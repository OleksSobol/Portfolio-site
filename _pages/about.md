<section style="margin: 3rem 0;">
  <div class="md-card">
    <h2 style="font-size: 1.6rem; color: var(--md-sys-color-primary);"><i class="fas fa-quote-left"></i> The Journey</h2>
    <p style="font-size: 1.05rem; line-height: 1.8;">
      My path into software development started with frustration. As a network engineer managing hundreds of ISP devices, I watched colleagues spend hours on tedious, repetitive manual provisioning tasks. So I wrote my first Python script to configure network equipment in bulk. That single script saved 5 hours every week.
    </p>
    <p style="font-size: 1.05rem; line-height: 1.8;">
      One script became ten. Ten scripts grew into full production systems. What started as simple CLI automation evolved into robust web applications serving thousands of real users. Today, my systems handle ISP customer onboarding, hardware lease tracking, and operational billing — running reliably in production with 99.9% uptime.
    </p>
